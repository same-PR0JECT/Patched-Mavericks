# Patched-Mavericks
<br>
<p>This is no ordinary version of the Mavericks we all love. I have made almost everything functional, such as iMessage, iTunes login, and more. Details about the specifics are listed below.</p>
<br>
<h2>What works</h2>
<ul>
  <li>iMessage [ Uses <a href="https://github.com/Wowfunhappy/AquaTransport">AquaTransport</a> by <a href="https://github.com/Wowfunhappy">Wowfunhappy</a> to work ]</li>
  <li>FaceTime [ Uses <a href="https://github.com/Wowfunhappy/AquaTransport">AquaTransport</a> by <a href="https://github.com/Wowfunhappy">Wowfunhappy</a> to work; signs in but making calls does not work at the moment ]</li>
  <li>iTunes [ You may need to update to the latest version. In my experience it works better, plus you get Apple Music capability. ]</li>
  <li>Safari [ <a href="https://github.com/Wowfunhappy/WebKit">Modern MacOS 27 Golden Gate WebKit ported to MacOS X 10.9.5 Mavericks</a> by <a href="https://github.com/Wowfunhappy">Wowfunhappy</a> ]</li>
  <li>Mail [ Security patches that make modern emails function properly by <a href="https://github.com/Wowfunhappy">Wowfunhappy</a> ]</li>
  <li>iCloud [ Uses <a href="https://github.com/Wowfunhappy/AquaTransport">AquaTransport</a> by <a href="https://github.com/Wowfunhappy">Wowfunhappy</a> to work ]</li>
</ul>

<p>This is still being written, so be patient.</p>
